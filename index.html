Portway

A .NET to Spring Boot migration assistant

Teams moving from .NET to Java usually rewrite by hand, and asking an LLM to translate whole files gives code nobody can trust. Portway parses C# with ANTLR into a language-neutral model, translates it with tested rules, and calls an LLM only for the method bodies the rules can't handle. Every generated file is compiled, and anything that fails becomes a clearly marked stub for a human.

  • 14 of 16 method bodies on the sample API translated by rules alone
  • The generated app runs against PostgreSQL
  • Java 21, Spring Boot 3.5, Docker, GitHub Actions CI

From Pixels to Topology

MSc practicum with Aishwarya Shekar, accepted as a poster at AICS 2026

Crack masks tell you which pixels are damaged, but not how the damage connects. We segmented cracks with a U-Net that has a Vision GNN in its bottleneck, skeletonised the masks into graphs, and trained graph neural networks to find nodes with a hidden connection after 20% of edges were removed.

  • 4,769 road images from 6 public sources, deduplicated
  • Segmentation: 0.63 crack IoU, 0.77 Dice
  • GINE beat a structure-blind MLP by 47% on node prediction

AI-Generated Image Detector

DCU 2026 machine learning challenge

Is a photo real or made by a generator? The detector combines what large vision models see (CLIP and DINOv2 embeddings) with forensic traces that generators leave behind: frequency spectrum, error levels and sensor noise. A stack of logistic regression and residual MLPs makes the final call.

  • Out-of-fold F1 0.917, ROC-AUC 0.972
  • 4,800 images, threshold tuned on out-of-fold predictions

CrackMark

Built with a collaborator

Labelling cracks by hand is slow. CrackMark loads a folder of road photos, proposes a crack mask from the trained segmentation model, and lets you correct it with a brush. Each correction fine-tunes the model in the background, so the suggestions get better as you work.

  • Runs in the browser with a Python model server
  • Per-blob mask thinning to keep thin cracks thin
